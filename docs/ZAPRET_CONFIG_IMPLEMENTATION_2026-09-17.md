# Обновление конфигов и zapret2

17 сентября 2026 года. Обновлены каталог Obsession, проверка кандидатов и движок zapret2: закреплённый 1.0.5.2-h2 / Lua API 6. Исходный архив пользователя сверён с SHA-256 официального релиза GitHub.

## Изменения

- Перенесены пять защитных патчей Obsession на upstream `6b6c63e3385fa73f8af3be4a69171e947f5a319d`. В патчах 1 и 3 убраны уже реализованная upstream проверка длины и изменение удалённой функции `ReasmResize`; остальные три патча неизменны. Обновлены EXE, Lua, lock-файлы и реестр целостности. Две чистые сборки дали одинаковый SHA-256 EXE `d2a3dc3f6bb11f343e6ff74fa083a03e973ddb36d1901632d5ccfc07ccc2912e`.
- Версия движка сравнивается по четырём компонентам и отображается как `1.0.5.2`. Пак требует `>=1.0.5.2`; более старый движок отклоняется, повреждённые версии не принимаются. Кеш адаптивного подбора получает новую полную версию.
- Исправлен формат абсолютных путей в аргументах и конфиге службы: префикс `\\?\` убирается только при передаче проверенного файлового пути движку. Иначе Legacy не мог прочитать fake-файлы. Проверки целостности и ACL остаются на канонических путях.
- В Legacy `universal_5.conf` исправлена опечатка `host##www.google.com` → `host=www.google.com`, найденная настоящим парсером winws.
- Во всех 10 Legacy-конфигах Discord добавлен UDP 19294–19344, и в перехват, и в профиль Discord/STUN.
- В 15 игровых Legacy-конфигах широкие UDP-профили ограничены существующим `ipset-gaming.txt`. Такое же ограничение добавлено к широким TCP-профилям, где оно отсутствовало. Этот список всё ещё охватывает широкую инфраструктуру; это не классификатор конкретной игры.
- В списке YouTube/Twitch активированы шесть ранее закомментированных доменов Twitch.
- Пакет `builtin.base` обновлён с 0.6.0 до 0.7.0: 19 профилей. Каждый из четырёх уровней Discord содержит TLS, QUIC и голосовой discovery/STUN. TLS-профили охватывают также альтернативные порты 2053, 2083, 2087, 2096, 8443.
- Голосовые профили ограничены UDP 3478–3480, 19294–19344, 50000–50100, L7 `discord,stun`, payload `discord_ip_discovery,stun` и первыми пятью пакетами данных. Применяется шестикратный fake с 16 нулевыми байтами. Это кандидат для испытаний, а не подтверждённая универсальная стратегия.
- Приложение и служба не привязывают к discovery/STUN доменный список. QUIC override выбирает именно QUIC, не произвольный UDP-профиль. Голос в описании профилей отмечается как не проверенный активно.
- HTTPS-проба читает тело до конца либо до лимита 256 КиБ. Обрыв и зависание после заголовков считаются ошибкой. В деталях отображается число прочитанных байт и завершённость ответа/достижение лимита.
- QUIC-проба выполняет HTTP/3 GET и читает тело с тем же ограничением. Одного QUIC-рукопожатия недостаточно. HTTP/3 использует существующий Quinn с `h3` 0.0.8 и `h3-quinn` 0.0.10; сертификат сервера проверяется.
- Повторные подтверждённые ошибки чтения HTTP не маскируются пассивным сигналом ServerHello от Eyes.
- Удалён условный `rr1---sn.googlevideo.com` из metadata пакета. Это не заменено обещанием автоматической проверки реального видео.

## Проверка перед сборкой

В `ObsessionTauri`:

```powershell
npm run audit:dpi
npm run test:dpi-configs
npm run verify:dpi-parsers
node scripts/audit-dpi-configs.mjs --json
```

Аудит проверяет наличие capture-портов для фильтров, ограничение широких диапазонов по ipset, наличие файлов-зависимостей, hash файлов Lua-пакета, состав TLS/QUIC по уровням, голосовые профили Discord и необходимые медиадомены. Он вызывается автоматически в `prepare-runtime.mjs` до подготовки пакета.

`verify:dpi-parsers` дополнительно запускает штатные winws/winws2 с `--dry-run` в отдельной копии ресурсов. Проверяются 44 Legacy-конфига и 24 варианта zapret2: три категории × четыре уровня × обычный/адаптивный TLS-профиль. IPC-уровень 0 означает максимальный профиль, уровни 1–3 — явный выбор. В Legacy флаг проверки записывается внутрь временного response-файла: аргументы после `@file` движок игнорирует. Используются таймаут 15 секунд и непривилегированный `RunAsInvoker`. Dry-run не выполняет Lua-десинхронизацию и не проверяет обход блокировок.

Старые имена Legacy-конфигов сохранены. Формат настроек и версия IPC не менялись. Для работы установленного приложения новые ресурсы и служба должны попасть в обычное обновление установщика; изменение файлов репозитория не обновляет установленную службу.

## Выполненная проверка

- `cargo test --manifest-path ObsessionTauri/src-tauri/Cargo.toml --lib --locked --offline`: 693 теста, все прошли.
- `cargo test --manifest-path ObsessionTauri/runtime-service/Cargo.toml --lib --locked --offline`: 138 тестов, все прошли. Для Windows named pipe нужен запуск вне ограниченной песочницы.
- `node --test ObsessionTauri/scripts/audit-dpi-configs.test.mjs`: 5 тестов, все прошли.
- Локальные HTTP/HTTP3-серверы проверяют передачу 64 КиБ, обрыв/зависание после 16 КиБ, лимит размера, QUIC без HTTP/3 и HTTP/3 с зависшим телом. Тестовый сертификат создаётся через dev-зависимость rcgen; доверие ему не включено в продукт.
- `node ObsessionTauri/scripts/prepare-runtime.mjs --dry-run-engines`: release-сборка службы, проверка материализации и 68 успешных проверок парсерами. Сгенерирован локальный runtime-manifest с актуальными хешами.
- Форматирование изменённых Rust-файлов и `git diff --check` прошли.
- GitNexus восстановлен полным переиндексированием. `detect-changes --scope all` отметил HIGH для совокупности изменений в запуске/сборке профилей; просмотренный diff соответствует затронутому пути. Его список не включает новые untracked-файлы, которые проверены отдельно.
