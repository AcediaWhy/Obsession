# Сжатие пакета установщика

Сборщик установщика встраивает машинный пакет, сжатый gzip. Загрузка runtime из сети и внешний распаковщик не нужны; UPX не используется.

## Формат

Внешняя оболочка состоит из `OBSGZIP1` (8 байт), несжатой длины (u64, little-endian), SHA-256 несжатого пакета (32 байта) и ровно одного элемента gzip. Его содержимое — прежний пакет `OBSMACH1` без изменений. Worker по-прежнему принимает старые несжатые пакеты `OBSMACH1`.

Перед подготовкой файлов декодер проверяет предел размера, целостность gzip, точную длину распакованных данных, SHA-256 и отсутствие дополнительных элементов или данных в конце. Вложенное сжатие отклоняется. Продолжают действовать проверки внутреннего манифеста, хешей отдельных файлов, версии и безопасных путей. Хеши проверяют целостность, но не заменяют подпись издателя.

Входной и распакованный пакеты ограничены 512 MiB. Декодер читает не больше заявленной распакованной длины плюс один байт. Владение файлами сейчас требует копирования распакованного содержимого, поэтому временное потребление памяти может приближаться к удвоенному размеру несжатого пакета, дополнительно к встроенному архиву и расходам приложения.

## Проверки

Из корня приложения:

```powershell
node --test scripts/payload-compression.test.mjs
cargo test --manifest-path installer/src-tauri/Cargo.toml --lib --offline payload -- --test-threads=1
cargo test --manifest-path installer/src-tauri/Cargo.toml --lib --offline machine_worker::tests::machine_update -- --test-threads=1
node scripts/build-setup.mjs
cargo test --manifest-path installer/src-tauri/Cargo.toml --lib --offline built_compressed_machine_payload_is_authenticated -- --ignored --nocapture
```

Тесты проверяют некорректные и обрезанные архивы, ложные длины, чрезмерное увеличение при распаковке, ошибки хеша и CRC, дополнительные элементы gzip, небезопасные внутренние пути, подготовку файлов и обновление с откатом. Для этого используются временные тестовые данные и имитация службы. Тест с флагом ignored проверяет настоящий созданный пакет после сборки. Установку и обновление с повышенными правами отдельно проверяют в одноразовой Windows VM по [списку перед выпуском](../docs/RELEASE_CHECKLIST.md).
