# Проверка перед релизом — 23 сентября 2026

## Изменения

- Провайдеры hosts загружаются независимо: отказ второго источника не блокирует первый.
- Gemini: ручной GeoHide / Astracat либо Auto (GeoHide → Astracat → Xbox → Comss).
  Ручной выбор сохраняется в состоянии службы и переживает повторную установку hosts.
  Неудачный ручной выбор не заменяет работающие записи и сохранённое предпочтение.
- IPC v4: новый интерфейс и старая служба несовместимы намеренно. Обновлять вместе
  через установщик; один новый exe поверх старой службы недостаточен.
- Повторные нажатия удерживаемой горячей клавиши и параллельные переключения из
  трея объединяются. В журнале фиксируются входы UI / tray / hotkey / onboarding
  и наблюдаемый статус при открытии. Это НЕ доказательство устранения сообщения
  друга о включённом DPI при первом открытии: воспроизведения пока нет.
- Без WebView2 сначала предлагается загрузить подписанный Microsoft bootstrapper.
  Отмена/ошибка не устанавливают Obsession. Деинсталляция без WebView2 по-прежнему
  доступна. Shared WebView2 не удаляется деинсталлером Obsession.

## Обязательный прогон в одноразовой Windows VM — ещё НЕ выполнен

Сначала snapshot VM. Не выполнять полный uninstall на рабочей машине ради теста.

1. Чистая Windows, нет Obsession: установить, отменив предложение автозапуска
   приложения, проверить службу и отсутствие winws. Перезагрузить Windows,
   открыть Obsession впервые. DPI должен оставаться выключенным без нажатия
   «Включить» или «Применить и проверить» в начальной настройке.
2. Повторить с WebView2 и без него. Без WebView2: отмена native prompt, отсутствие
   сети, успешная установка runtime; только затем бумажный UI Obsession. При
   ошибках не должны появляться файлы/служба Obsession. Не отключать проверку подписи.
3. Старый релиз + служба IPC v3 → новый setup. Проверить обновление службы до v4,
   сохранение настроек, GeoHide/Astracat, отмену UAC и восстановление при ошибке.
4. Включить/выключить DPI обоих движков; удерживать хоткей, быстро нажать трей.
   Не должно быть очереди повторных переключений. Проверить X в трей, полный
   «Выход», аварийное завершение UI, повторный запуск и перезагрузку Windows.
5. Удалить с сохранением настроек → установить заново → удалить полностью.
   Проверить службу, Program Files, принадлежащие программе записи hosts,
   ярлыки и пользовательские каталоги по `installer/UNINSTALL.md`. Посторонние
   записи hosts и данные других программ должны сохраниться.
6. Повторить удаление с изменённым hosts, недоступной службой и занятыми файлами.
   Нужны явные ошибки/repair или информация об остатках, а не ложное «удалено».

При повторении DPI-багa сохранить журнал начиная со строки «Открытие Obsession»
до появления активного статуса. Не присылать Google cookies, токены или пароли.
