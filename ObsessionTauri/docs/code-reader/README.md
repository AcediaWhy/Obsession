## Как поделиться

**Другу:** отправь ссылку на страницу нужного пакета. Код свёрнут по файлам; открой интересующий блок. Схема и карта в начале объясняют связи между модулями.

**Нейронке:** передай Raw-ссылку из таблицы или сохрани её содержимое как `.md` и прикрепи в чат. Пакеты объёмные — лучше отправлять по одному и указывать конкретный вопрос. Если модель не умеет открывать ссылки, используй файл.

Ссылки Raw в таблице ведут на текущие документы в `main`; версия вложенных исходников указана в каждом документе. Для неизменяемой ссылки на сам документ замени `main` или `refs/heads/main` на хеш коммита, добавившего пакеты.

## Полнота и происхождение

- Во встроенных файлах сохранены комментарии, тесты и исходные строки. Между ними добавлены только пояснения и Markdown-разметка.
- В каждом пакете есть прямые ссылки на исходные файлы и дополнительные модули того же коммита.
- Набор файлов, размеры и SHA-256 записаны в [snapshot.json](snapshot.json).
- Зависимости, сборка и проверки описаны в [руководстве разработчика](https://github.com/AcediaWhy/Obsession/blob/111889a8144070b8f2259252e1c905370b39d13b/ObsessionTauri/README.md).

## Обновление пакетов

Из корня репозитория:

```powershell
node ObsessionTauri/scripts/export-code-reader.mjs v1.2.0
node ObsessionTauri/scripts/export-code-reader.mjs v1.2.0 --check
```

Первая команда собирает документы из Git-коммита, вторая проверяет их соответствие источнику без записи файлов. Для нового снимка укажи другой существующий тег или коммит.
