# DNS: отменённое изменение и совместимость отката

Автоматическая смена DNS из версии с политикой adaptive_causal_experiments_v4
отозвана 2026-10-01 после неуспешных замеров и сообщения о разрыве VPN.
Резервный DNS не используется. Подбор работает через текущий resolver Windows.

Новая служба отклоняет FlushSystemDns и RepairSystemDns даже от
аутентифицированного клиента. Функция установки DNS не компилируется в
production. Приложение не содержит автоматической ветки смены DNS или очистки
системного cache. Capability SystemDnsRestore означает только чтение старого
журнала и явное восстановление по кнопке в настройках.

Для обновления с проблемной версии сохранена совместимость старого журнала
C:/ProgramData/Obsession/Runtime/dns-settings/recovery.json. Если журнала нет,
восстановление ничего не записывает. Если настройки изменены сторонним
приложением или пользователем, откат отказывается их перезаписывать.
Пользователю, уже исправившему DNS вручную, повторный откат не нужен.
Удаление приложения поддерживает возврат принадлежащего Obsession старого
изменения, но не устанавливает новый DNS.

О текущем исправлении порядка измерений см.
[ADAPTIVE_EXPERIMENT_PLANNER.md](ADAPTIVE_EXPERIMENT_PLANNER.md).
