# Диагностика Obsession

## Результаты проверки DPI

Автоподбор проверяет конкретные HTTPS-адреса выбранной категории. Отчёт содержит результат каждого адреса, HTTP-статус, число попыток, прочитанные байты, время и транспортные ошибки.

| Результат | Значение |
| --- | --- |
| `passed` | Все проверки категории завершились успешно. |
| `partial` | Успешна только часть проверок. |
| `failed` | Проверки не подтвердили доступность. |
| `cancelled` | Проверку отменили. |

Автоподбор сохраняет конфигурацию только при полном успехе. Если ни один кандидат не прошёл проверку, прежний выбор сохраняется, но не получает отметку об успешной проверке. Отмена останавливает только временный сеанс теста; ошибка его остановки прерывает автоподбор. Проверка не должна завершать уже работающий пользовательский сеанс.

Для Discord проверяются gateway, манифест обновления и публичный аватар CDN. Для изображений проверяется содержимое ответа: HTML, HTTP-ошибка или обрезанный файл не считаются успехом. Транспортная ошибка допускает одну повторную попытку; HTTP 4xx повторно не запрашивается.

Эти результаты не подтверждают работу всех медиа, звонков или воспроизведения видео. Время включает соединение и повторные попытки. Небольшой аватар подходит для проверки доступности, но не для измерения скорости загрузки. Таймаут одного адреса нужно оценивать вместе с остальными результатами и поведением самого приложения.

## Конфигурации Discord

Конфигурация выбирается вручную или через автоподбор. Универсального лучшего номера нет: результат зависит от сети и фильтрации провайдера.

Варианты `discord_15.conf` и `discord_16.conf` отличаются от `discord_14.conf` числом повторов TCP fake-пакетов: 4 и 2 вместо 8. Меньшее число повторов может снизить надёжность обхода; подтверждённого преимущества по скорости у этих вариантов нет. При сравнении используйте одинаковые файлы Discord CDN и отдельно проверяйте gateway, обновление клиента и звонки. Ресурс вне списка хостов Discord не подходит для прямого сравнения этих конфигураций.

Источники отдельных конфигураций указаны в их заголовках. Версия исходного пакета Flowseal и хеши зафиксированы в [файле происхождения ресурсов](../third-party/flowseal/legacy-1.10.3.lock.json). BAT-файлы исходного проекта не выполняются.

## Процессы Legacy и TCP timestamps

Выбранные категории Legacy объединяются в один подготовленный response-файл и один процесс `winws`, принадлежащий службе. Это исключает конкуренцию отдельных процессов за пересекающиеся фильтры захвата. Несколько выбранных категорий в интерфейсе не означают несколько процессов Legacy.

Если проверенная конфигурация Legacy содержит точное значение `ts` в `--dpi-desync-fooling` или `--dup-fooling`, служба временно включает TCP timestamps. Zapret2 этого изменения не запрашивает. Перед изменением исходное значение сохраняется в защищённом файле:

```text
%ProgramData%\Obsession\Runtime\tcp-settings\timestamps.restore
```

Настройка действует на весь компьютер. Если timestamps уже включены, служба не меняет их. Возврат исходного значения выполняется после остановки задачи DPI, а при ошибке запуска — после закрытия неудачной задачи. Неудачное восстановление сохраняет журнал для повторной попытки при старте службы или перед следующим запуском.

Повреждённый журнал блокирует операцию. Не удаляйте его ради сброса ошибки: сначала устраните причину восстановления. Внешнее изменение на `allowed` или `disabled` сохраняется; внешнее изменение на такое же `enabled` нельзя отличить от изменения службы. У уже открытых TCP-соединений параметры заново не согласовываются, поэтому после включения новой конфигурации перезапустите проверяемый клиент.

## Служба и журналы

Привилегированные операции требуют установленной совместимой службы `ObsessionRuntime`. При недоступной службе, несовместимом протоколе или неподтверждённых ресурсах приложение блокирует операцию. Для обновления приложения и службы используйте установщик.

Браузерная лаборатория показывает демонстрационные статусы и не подтверждает работу DPI. Изменения Rust требуют пересборки и перезапуска нативного приложения; изменения защищённых ресурсов требуют обновления установки.

Для разбора проблемы сохраните время события, движок, выбранные категории и конфигурации, результаты по адресам и относящийся к событию участок журнала. При проблеме первого запуска полезен участок от строки «Открытие Obsession» до появления статуса DPI. Перед публикацией скриншота сведения о текущей сети можно скрыть кнопкой с глазом на карточке «Сеть».

Ошибка установки записывается в:

```text
%LOCALAPPDATA%\vlarpsu\Obsession\installer.log
```

Правила хранения и границы привилегий описаны в [архитектуре runtime](SECURE_RUNTIME_ARCHITECTURE.md), порядок удаления — в [руководстве деинсталлятора](../installer/UNINSTALL.md).
