Пользователь: «0 прогресса, абсолютно». Последний полный сетевой запуск
`measurement-20261002T191501.429699600Z-25724-0.jsonl` — 12 завершённых
кандидатов, 0 рабочих вариантов, 89.552 с, `budget_expired`. Исходный конфиг
возвращён; исходные проверки до и после не прошли. Это не успешный обход.
SHA-256 отчёта: `3b61a057e35bb4a220acd5449f0b80338fe045431dd3839bbefe53401f6aca95`.

В каждой попытке обязательный API `discord.com` на `162.159.136.232:443`
завершался `tcp_failed`: не было установленного сокета, ClientHello и исполнения
TLS-программы. Другой обязательный адрес, `gateway.discord.gg` на
`162.159.130.234:443`, устанавливал TCP. В 11 попытках его TLS зависал без
продвижения ACK; в последней соединение закрылось с Windows error 10054.
Пассивный сенсор в последней попытке также видел ACK 680, TLS alert и reset,
без ServerHello. Это не TLS/HTTPS-успех и не доказательство полезного прогресса.
Точная причина сетевого отказа и отправитель ответа не установлены.

Исправленный штатный `tls_client_hello_clone` теперь вызывался вместе с fake
и сегментацией без прежнего `invalid_plan`. Исправление исполнения не принесло
сетевого успеха. Последующий обычный запуск
`measurement-20261002T191652.692947800Z-25724-1.jsonl` отменён пользователем
после 27.546 с: 4 начатых кандидата, 3 завершённых наблюдения, тот же отказ API.
SHA-256: `9ea23e90352729a905d4365f96204b52c0aff3fb211941fe447ba512975199a1`.

## Два обнаруженных дефекта

1. `bounded_addresses` сам сохранял только один адрес каждой IP-семьи. Поэтому
   `address_count: 1` в старом отчёте не означает, что Windows вернул только один
   A-record. Полный текущий системный ответ содержал пять IPv4: 135.232,
   136.232, 128.233, 137.232, 138.232 в сети 162.159.0.0/16. Этот ответ получен
   позже; восстановить полный ответ DNS во время старого теста невозможно.
2. `MeasureTcpRoute` требовал TCP-отказа сразу всех основных целей. Система
   продолжала менять TLS-программы по gateway, хотя обязательный API не мог
   дойти до ClientHello. Она также разрешала отрицательное обучение общей
   стратегии и запись истории по этому смешанному результату.

## Изменение

- Сохраняются до 8 уникальных адресов из текущего системного ответа DNS;
  порядок внутри семьи сохраняется, IPv6/IPv4 чередуются. Основные HTTPS-пробы
  и вспомогательные TLS-пробы проверяют эти адреса параллельно с одним исходным
  дедлайном. Время поиска и количество TLS-кандидатов не увеличены.
- В отчёт DNS записываются сохранённые адреса, лимит и
  `address_policy: bounded_system_answers_v2`. Ни настройки DNS, ни hosts,
  ни маршруты этой правкой не меняются.
- При отказе TCP у обязательной authority TLS-поиск прекращается после
  проверенного возврата исходной конфигурации. `tcpUnavailableAuthorities`
  сохраняет конкретные host:port. TLS-ранжирование, синтез и история не получают
  отрицательную оценку этого результата. Уже наблюдавшийся TCP к той же
  authority и вспомогательный отказ TCP не становятся таким запретом.
- Парная проверка предпочитает IP успешной основной HTTPS-пробы из полной
  подтверждённой серии, если он есть в подготовленном DNS. Это отдельная
  неизменяемая копия; cache для восстановления не заменяется. При отсутствии
  подтверждённой серии сохранён прежний выбор IPv4; fixed replay сохраняет
  закреплённый адрес. Сертификат и имя TLS проверяются как раньше.

## Проверка и предел результата

912 app-тестов прошли, 3 внешних/служебных теста пропущены. Регрессии проверяют
второй–восьмой IPv4 после отказа предыдущих, третий адрес после двух зависших
TLS-handshake, недоступный API одновременно с исполнением на gateway,
запрет обучения и перехода к следующей программе после отката, а также
сохранение подтверждённого IP в парном сравнении и отказ от чужих/неуспешных
подсказок. Локальные TLS-серверы и тестовые сертификаты не подтверждают обход
на провайдере.

Измерительный клиент может выбрать ответивший альтернативный IP. Эта правка
не переназначает адреса приложения Discord: если само приложение не перейдёт
к доступному адресу, успешная измерительная проба не докажет его работу.
Проверка реального клиента остаётся необходимой.
