# Цвета темы в автоподборе

Карточки автоподбора, рамки, глубина, кнопки подбора и применения, раскрытые профили, точечная вуаль, анимация и статический fallback используют основной `--accent` выбранной темы. Тёмные поверхности и светлый текст смешиваются с акцентом, сохраняя читаемость. Зелёный статус успешных сетевых проб сохраняет своё значение.

| Тема | Основной акцент RGB |
| --- | --- |
| Golden Meadow | 220 177 103 |
| Aurora | 99 102 241 |
| Alchemist | 185 216 155 |
| Rain | 122 152 190 |
| Midnight | 202 214 226 |
| Catnap | 244 150 88 |
| Fallen Down | 206 74 82 |
| Yani Neko | 232 137 46 |

Цвет Canvas читается из унаследованной CSS-палитры. Наблюдатель реагирует только на изменение `data-theme` у предков, обновляет uniform цвета и фона и отключается при размонтировании. Сцена не пересоздаётся, степень сборки и скорость перехода сохраняются. В режиме без движения смена темы требует одного нового кадра, после чего кадры снова останавливаются. Покадрового опроса темы нет.

Акценты Golden Meadow перенесены в глобальный stylesheet: теперь они доступны до загрузки фоновой сцены. Белый цвет значка в шейдере заменён цветом темы; светлые блики остаются слабыми.

Проверено 73 тестами: автоподбор, API, настройки, сценарии, планировщик кадров, Canvas и наблюдатель палитры, жизненный цикл темы и Golden Meadow. Браузерная проверка в изолированном макете: восемь цветов, смена темы на собранном до 0.550 значке без сброса, цвета карточек и кнопок применения, режим без движения (4 кадра до и после повторного наблюдения), отсутствие горизонтального переполнения при 800×600. Проверки базового интерфейса предыдущей сборки сохранены в `ZAPRET2_PATTERN_WAVES_BUILD_2026-10-05.json`.

Сборка выполняется штатным `npm run build:setup`; после неё проверяются файлы payload, его наличие внутри setup, подпись update-манифеста, встраивание новых JS/CSS и неизменность runtime и рабочих профилей относительно TLS v4. Результат фиксируется в `ZAPRET2_PATTERN_WAVES_THEMED_BUILD_2026-10-06.json`. Установщик не запускается, реальный сетевой подбор при визуальной проверке не выполняется.
