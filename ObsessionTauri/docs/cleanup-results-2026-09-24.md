## Проверки

- `npm run build`: успешно; в корне `dist` единственная HTML-страница `index.html`.
- `npm test`: 111 файлов, 487 тестов прошли.
- 25 перенесённых HTML сопоставлены с HEAD: содержимое совпало после нормализации LF/CRLF.
- Временный Vite-сервер отдал все 26 страниц, включая новый каталог; обработаны общие стили, `overviewDev.tsx`, `earLab.tsx`, `yaniDev.tsx`.
- Это проверка доставки и преобразования страниц, не визуальный прогон всех старых лабораторий.
- GitNexus `detect-changes`: низкий риск, затронутых execution flows нет. Переносимые новые файлы дополнительно проверены по содержимому, поскольку они ещё не staged.
- `git diff --check`: успешно.
- Rust и Setup заново не собирались: Rust-код и поставляемые бинарники не менялись. Существующий Setup не содержит изменение frontend-конфигурации; оно войдёт в следующий установщик.

## Что осталось осознанно

Исходники арта, tracked-исследования в `artifacts` и общие модули тем сохранены. Они занимают десятки мегабайт и требуют отдельного решения о судьбе каждого прототипа. Общий Cargo target-dir не включался: скрипты сборки используют конкретные пути crate/target, и такая настройка требует отдельной проверки сборки.

Подробности исходного состояния: [аудит](storage-audit-2026-09-24.md). Его цифры и пути относятся к состоянию до очистки.
