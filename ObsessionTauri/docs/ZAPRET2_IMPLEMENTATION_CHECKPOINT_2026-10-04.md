# Первый шаг реализации турнира Zapret2

Дата: 4 октября 2026 года. Выполнена основа этапов 1–2; существующий подбор сохранён. Это ещё не выпуск турнира или сборщика.

Продолжение реализации и актуальные ограничения: [второй шаг](ZAPRET2_TOURNAMENT_CHECKPOINT_2026-10-04.md).

## Что доступно в коде

Пакет builtin обновлён до 0.12.0, схема — до 2. В нём 19 стандартных правил, 32 прежних пресета, 11 новых исследовательских пресетов и прежний эксперимент ClientHello. Старую схему 1 по-прежнему можно читать; новые поля в ней отклоняются.

Новые пресеты включают по пять TLS-вариантов для Discord и YouTube: раннюю перестановку, изменение TCP window с перестановкой, несколько границ SNI, hostfakesplit с bad ACK и hostfakesplit с MD5. Для YouTube также добавлена точка QUIC fake с четырьмя повторами. Полный исходный контекст и ограничения находятся в документе исследования. C06 пока не перенесён.

Метаданные хранят источник, семейство, происхождение сообщения об успехе и оговорки. Сообщение автора и успешный blockcheck не являются результатом на компьютере пользователя. Это не полноценная модель допуска: отдельные локальные и сетевые результаты будут введены следующим шагом.

Для каждого Lua-действия схема позволяет отдельно задать payload и входящий/исходящий диапазон. Пропущенный диапазон наследуется от профиля, а не от предыдущего действия. При отсутствии диапазона используется явное `a0`. Старая форма `desync` продолжает работать; смешивать её со стадиями `steps` нельзя. Общий код в runtime-protocol собирает последовательность действий для приложения и службы. Это типы ресурсов, не новые произвольные параметры IPC: служба получает выбранные ID и читает проверенный пакет.

В интерфейсе появилась группа «Исследовательские профили» и раскрываемые условия со ссылкой на источник. Эти профили выбираются вручную. Текущая кнопка подбора может проверить уже выбранный исследовательский профиль, затем попробовать обычные варианты. Остальные исследовательские профили автоматически не перебираются до введения повторных замеров. Результат по-прежнему означает существующий набор веб-проверок или QUIC handshake, а не подтверждение воспроизведения видео/голоса.

## Выявленный отказ C05

Вариант `fake:tcp_ts=-10000:tcp_seq=400` с последующим разбиением сохранён только в `scripts/fixtures/zapret2-quarantined-recipes.json`. Обе адаптации удалены из выбираемого пакета.

На большом ClientHello без TCP timestamps смещение fake на +400 помещает его внутрь принимаемого TCP-потока. В модели приёмника появляются конфликтующие байты. При наличии timestamps модель может отвергнуть этот fake по устаревшему timestamp; это условие нельзя молча предполагать для всех подключений. Тест сохраняет четыре воспроизводимых контрпримера: две адаптации × ранний/поздний SNI. Это основание отказать рецепту в текущем допуске, не утверждение о поведении каждого реального сервера.

## Проверки

Все перечисленные проверки завершились успешно:

- 4 теста общей схемы: порядок областей, сброс диапазонов, старая форма, границы и строгость метаданных.
- 36 тестов dpi_engine в приложении; 13 тестов компилятора пакета в службе.
- 10 тестов текущего подбора, включая возврат исходного запроса, отмену, ошибки запуска/возврата и допуск явно выбранного исследовательского профиля.
- 31 тест интерфейса/store и контрактов backend; TypeScript и production-сборка интерфейса.
- 7 статических аудитов; native CLI проверки 32 прежних и 11 новых пресетов. Хеши 19 стандартных правил и прежнего эксперимента остались прежними.
- 78 прежних offline LuaJIT проверок ClientHello и 104 новых проверки рецептов, включая 20 полных аутентифицированных TLS1.2/TLS1.3 + HTTP обменов и четыре контрпримера C05.
- Полная подготовка локального защищённого runtime-пакета и проверка через materializer службы: 62 явных выбора профиля Zapret2, 224 комбинированных Legacy-плана, 354 запуска parser-only `--dry-run`.

Стенд использует bundled Lua без изменений, независимый oracle позиций SNI, записывающий rawsend и модель сборки TCP. Отбрасывание fake по bad ACK, MD5 и устаревшему TS моделируется явно. Проверка не устанавливает фактическое отбрасывание пакетов сервером, WinDivert-доставку, точность нативных маркеров, исполнение wssize на SYN с действующим hostlist/L7, работу DPI или сервисов. QUIC-пресет прошёл только проверки ресурсов/CLI. Установленная служба и живое подключение этим стендом не испытывались.

## Граница следующего шага

Следующим реализуется слой измерений по функциям сервиса: отдельные outcomes и причины, проверка пригодности целей, частичные результаты, ограничения transport и контекст исполнения. После этого текущий первый успех заменяется турниром с отбором финалистов, повторными раундами и чередованием порядка. Идентичность рецептов с версиями ресурсов, срок результатов и проверка применимости также ещё требуются.

Сборщик остаётся следующим этапом после измерений и турнира. Ему нужны реальные взаимодополняющие частичные успехи и возможность разделить их фильтрами движка. Отсутствие рабочего API/CDN у всех кандидатов не создаёт автоматически рабочую сборку.

## Воспроизведение

Из каталога ObsessionTauri:

```powershell
npm run test:zapret2-research
npm run test:dpi-configs
cargo test --manifest-path runtime-protocol/Cargo.toml zapret2_recipe --offline
cargo test --manifest-path runtime-service/Cargo.toml zapret2_pack --offline
cargo test --manifest-path src-tauri/Cargo.toml dpi_engine --offline
cargo test --manifest-path src-tauri/Cargo.toml protected_runtime::zapret2_picker --offline
npm test -- --run src/design/components/Zapret2StrategyPanel.test.tsx src/store/zapret2StrategyStore.test.ts src/lib/tauri.contract.test.ts src/lib/tauri.browser.test.ts
npm run build
node scripts/prepare-runtime.mjs --dry-run-engines
```

Для offline Lua нужен Python 3.11 и тестовая Lupa 2.6 (LuaJIT 2.1), а также OpenSSL CLI для временного сертификата. Зависимость не включается в приложение. В этой сессии она установлена в игнорируемый каталог `.dev-logs/research-lua-deps`:

```powershell
$env:PYTHONPATH = Join-Path (Get-Location) '.dev-logs/research-lua-deps'
python scripts/test-research-zapret2-luajit.py
```
