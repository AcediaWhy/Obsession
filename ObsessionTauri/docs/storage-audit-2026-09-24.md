**Удалять всё с Lab или labs в названии нельзя.** Проверены статические импорты от src/main.tsx и связи GitNexus:

- AlchemistRoom используется одновременно рабочим AlchemistField и лабораторной AlchemistComposition.

Статический обход нашёл 176 файлов от main.tsx без неразрешённых локальных импортов. Это вспомогательная проверка: она не доказывает отсутствие динамических URL, CSS-зависимостей или ресурсов; TypeScript местами разрешает JS через .d.ts. ## 6. Git и защита от повторного роста

История Git занимает около 366.97 МиБ. git count-objects сообщает 327,83 МиБ упакованных объектов, 3,48 МиБ loose objects и один временный объект около 34,93 МиБ. Это небольшая доля общего размера. Не удалять .git или pack-файлы вручную. Обслуживание через Git имеет смысл после проверки целостности, сохранения веток и завершения работающих Git-процессов.

После очистки:

1. Рассмотреть общий Cargo target-dir/workspace для родственных Rust-crate, чтобы сократить дублирование зависимостей. До изменения проверить жёстко заданные пути в build-setup.mjs, prepare-runtime.mjs и tgproxy-rs/scripts/build-for-obsession.ps1; общий каталог может потребовать исправления этих путей.
2. Завести отдельный запуск лабораторий и собирать в релиз только index.html.
3. Сохранять одну актуальную тестовую сборку и ограниченное число контрольных версий вне dist-release.
4. Вынести исследования, исходники арта и временные результаты в явно разделённые каталоги. Само перемещение внутри проекта уменьшит визуальный беспорядок, но не размер.
5. Добавить адресный сценарий очистки только генерируемых каталогов с предварительным списком путей и размеров. Не применять маски вида *lab* к исходникам.
