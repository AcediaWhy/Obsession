# Доступ при остановленном Obsession, 6 октября 2026

Пользователь сообщил, что при выключенном обходе и VPN Discord отправляет и
принимает новые сообщения, а YouTube воспроизводит ранее не открытый ролик.
В начале проверки системный прокси был выключен. Позже он включился на
`127.0.0.1:2080`; пользователь подтвердил, что сам включил NekoBox для чата.
Это изменение нельзя считать самопроизвольным включением VPN или объяснением
первоначального наблюдения.

До и после диагностических проб служба `ObsessionRuntime` остановлена,
процессы Obsession/winws отсутствуют. Обычный маршрут IPv4 — Wi-Fi через
`192.168.0.1`, разделяющих маршрутов `/1` не найдено. Активного адаптера TUN
не найдено, драйвер wintun остановлен. NekoBox, Happ и DNS-процессы остаются
в фоне. Discord и Zen имеют соединения с локальным портом NekoBox 2080;
это не устанавливает маршрут каждого их запроса.

Свежие curl-запросы с `--noproxy '*' --ipv4` получили HTTP 200 от Discord API,
Discord CDN и главной страницы YouTube. Успех YouTube-страницы не измеряет видео.
Discord по IPv6 не получил адрес DNS; YouTube по IPv6 не установил TCP в срок.
Следовательно, наблюдаемый успех прямых curl-проб не объясняется IPv6.

Запущен существующий явно выбираемый тест
`live_functions_without_runtime_mutations` из реального кода подборщика.
Он открывает собственные TCP/TLS/HTTP/WSS-соединения, не использует явный
системный/окруженческий прокси, не запускает и не останавливает runtime.
Тест не записывает успешные пробы в пользовательскую историю кандидатов.

За один контрольный прогон прошли 6/6 обязательных функций Discord: обе формы
большого ClientHello для API и CDN, REST, Gateway Hello, PNG и 512 КиБ JS-файла.
Файл загружен за 437 мс с учётом нового TCP/TLS/HTTP. У YouTube прошли 3/3:
страница, JPEG и 512 КиБ кода плеера. Этот тест не измеряет Discord READY,
голос или видеопоток. Необязательный Discord updater не завершился до окончания
обязательных проверок; полного успеха всех вспомогательных функций не заявляем.

Загруженный WinDivert найден. Перечисление его владельцев через безопасный
слой REFLECT с NO_INSTALL завершилось Windows Access Denied (5): текущий
процесс не имеет прав администратора. Дескриптор NETWORK не открывался,
драйверы не устанавливались и не останавливались. Нельзя объявить отсутствие
всех сторонних фильтров или туннеля на роутере доказанным.

Контроль показывает доступность тех же публичных проб при остановленном
Obsession в данный момент. Он не устанавливает причину изменения доступности,
не переносится задним числом на прошлые прогоны и не доказывает отсутствие
прозрачного обхода другими компонентами. Пара Hostfake + MD5 / Split SNI
действительно выполняла нужные блоки в прошлых испытаниях, однако из этого
не следует, что именно она обеспечивала доступ или улучшала его.

Для проверки эффекта кандидата нужен сравнимый контроль без Obsession рядом
по времени, затем проба кандидата и повторный контроль, со свежими сокетами,
одинаковыми целями/адресами и отдельно подтверждённым состоянием VPN.
Успешный контроль следует показывать как «доступно без Obsession»;
срабатывание двух блоков остаётся отдельным фактом выполнения сборки.

Чтобы отделить особенность ПК от общего сетевого пути, полезен контроль на
другом устройстве в той же Wi-Fi-сети без его VPN/обхода. Приложения и сетевые
настройки пользователя в ходе этой диагностики ассистент не изменял.

Подробная запись и хеш реального лога: `ZAPRET2_BASELINE_INVESTIGATION_2026-10-06.json`.
