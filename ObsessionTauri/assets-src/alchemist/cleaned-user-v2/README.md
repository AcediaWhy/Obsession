## Перед сборкой

Размеры отличаются от предыдущих заготовок: листы были 2172×724, теперь 1672×941. Старые координаты нарезки 724×724 неприменимы. ## Будущая оптимизация изображений

Пользователь попросил в будущем уменьшить вес изображений, включая остальные картинки проекта.
Для пиксельных спрайтов экспортировать WebP lossless с альфа-каналом, без ресайза и потерь. Сохранить исходные PNG вне runtime-каталога. Сравнить фактический вес и декодированное изображение; не обещать заранее процент экономии.
Для фотографий отдельно подобрать сжатие с потерями и нужные разрешения; не применять единый lossy-профиль ко всем ассетам. SVG не растрировать без необходимости.
Сначала завершить сборку и точки крепления, затем экспортировать используемые кадры/атласы и обновить пути. Массовая конвертация и изменения runtime сейчас не выполнялись.
