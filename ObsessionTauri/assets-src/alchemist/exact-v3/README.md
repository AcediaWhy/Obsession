# Алхимик: точные вырезки v3

Источник: пользовательский `Codex Image Sep 15, 2026, 01_46_24 PM.png`, сохранён без изменений как `reference.png` (1254×1254).

В исходнике шахматный фон запечён в RGB. Скрипт `tools/prepare_alchemist_exact.mjs` удаляет связанный с границами светлый нейтральный фон через alpha, не меняя RGB сохранённых пикселей. Генерация и независимое масштабирование деталей не использованы.

## Файлы

- `original.png` — очищенный эталон.
- `body`, `hat`, `eyes`, `flask`, `leftEar`, `rightEar`, `tail` — непересекающиеся вырезки в общей системе координат 1254×1254. Их наложение восстанавливает очищенный эталон без различий.
- `motion-base`, `tail-tip`, `roots` — производные точные вырезки для небольших движений.
- `backing`, `skin` — вспомогательные подложки: соседние пиксели ткани/шерсти перенесены в закрытые исходником области. Это НЕ исходная скрытая анатомия и не новые нарисованные кадры.
- `verification.json` — результаты сравнения и SHA256 исходника.

WebP lossless лежат в `public/lab-assets/alchemist-cat/exact-v3/`. Восемь загружаемых лабораторией изображений: 963778 байт против 2175150 байт PNG (−55,7%). Исходные PNG сохранены. Проверка декодирования WebP: без изменений alpha и видимых RGB.

## Анимация и ограничения

В нейтральной позе renderer выводит цельный эталон. В движении использует его вырезки с неизменным масштабом. Ушки отклоняются максимум на 2,8°, верх хвоста — на 4°; основание прикрыто исходными пикселями. Кривые ускорения/замедления и разнесённые паузы заменяют переключение трёх несовпадающих сгенерированных поз.

Моргание закрывает глаза подложкой шерсти и рисует линию века; глаза не растягиваются. Тело, шляпа и колба не деформируются. Колба пока неподвижна: исходник не содержит достоверного тела под ней. Поворот растровых вырезок всё ещё меняет дискретизацию контура; это ограничение техники, не набор вручную нарисованных кадров.

Работа подключена только к `alchemist-cat-lab.html`, не к основной теме. В лаборатории есть эталон без эффектов, отдельные режимы ушек/хвоста и покадровый ползунок.

Проверено: TypeScript без ошибок; 34 теста в четырёх модулях лаборатории. В браузере проверены нейтральная поза, закрытые глаза, отклонённое ушко и хвост. Для воспроизведения подготовки требуется sharp из установленного Codex runtime; путь указан в скрипте.
