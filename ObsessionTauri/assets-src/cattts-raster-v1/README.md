# Cattts — растровая проба 01

Открыть: http://127.0.0.1:1420/cattts-raster-lab.html после `npm run dev` из `ObsessionTauri`.

В пробе анимируются левое ухо кота, отдельная нижняя лапка и один правый лист. Кнопки позволяют повторить каждое движение, увеличить участок, остановить сцену, рассмотреть переход ползунком и сравнить с неизменённым исходником.

## Сохранённые материалы

- `original.png` — неизменённый PNG пользователя, 2048 × 2048.
- `animal-clean-plate.png` — восстановленная листва под животными, встроенный imagegen.
- `folded-pose.png` — новая крайняя поза уха и лапки, встроенный imagegen.
- `leaf-clean-plate.png` — восстановленная листва под правым листом, встроенный imagegen.
- `prompts.json` — точные три промпта и сведения об использованном режиме.
- `leaf-stencil.webp` — растровая маска выделения листа, первоначально полученная из прежней векторной разметки. От SVG она больше не зависит.

## Как устроена проба

Генерация меняет соседние детали, поэтому полные сгенерированные картинки не переключаются в сцене. Из новой позы извлекаются только силуэты уха и лапки. Между исходным и новым силуэтами заранее рассчитываются 49 растровых кадров посредством интерполяции полей расстояний. Это 49 вычисленных кадров из двух поз, а не 49 отдельно нарисованных или сгенерированных поз. Основание уха закреплено маской; цвет взят с тела исходного кота. Скрытый фон добавляется только там, где исходная деталь освобождает место.

Лист вырезан из исходного PNG с фактурой. Под ним используется восстановленный фон, согласованный по цвету с исходными краями. Он качается целиком с небольшой амплитудой. В браузере нет SVG, генерации изображений, вычисления контуров или постоянной деформации всего рисунка.

Ресурсы находятся в `ObsessionTauri/lab-assets/cattts-raster-v1/`. Страница загружает только `original.webp`, `ear-poses.webp`, `paw-poses.webp`, `leaf.webp`, `leaf-backing.webp` и `layout.json` — около 0,81 МБ. Остальные файлы в папке используются для подготовки. Папка находится вне `public`, чтобы Vite автоматически не копировал лабораторные материалы в сборку основного приложения.

Пересборка ресурсов из сохранённых исходников:

```powershell
node ObsessionTauri/tools/prepare_cattts_raster.mjs
```

Нужен Node и `sharp`; скрипт сначала ищет локальную установку, затем библиотеку в установленном окружении Codex. Сохранённые ресурсы уже готовы, пересборка для просмотра не требуется.

## Проверка и ограничения

В браузере проверены исходная, промежуточная и крайняя позы, крупный просмотр, сравнение и управление воспроизведением. При проверке исправлены несовпадение цвета у основания уха и тёмная кайма у листа. HTTP-загрузка и синтаксис JavaScript проверены.

Это небольшая проверка способа анимации, а не законченный риг персонажа. Переход контура уха ещё требует художественной оценки в движении. Правое ухо, мышонок, глаза и остальные листья в этой версии неподвижны. При сильном увеличении видно исходное растровое разрешение. Скрытая листва восстановлена предположительно — в исходнике этих участков нет.
