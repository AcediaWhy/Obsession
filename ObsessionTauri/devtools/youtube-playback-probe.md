# Прототип проверки видео YouTube

После успешного подбора раскрой «Результаты проверки» у YouTube и нажми
«Проверить видео». Приложение временно запускает найденную конфигурацию,
открывает отдельное окно WebView2 и возвращает исходную конфигурацию по
окончании. Проверку в своём браузере можно запустить в «Проверка вручную».

Автоматическое испытание использует публичное видео `jNQXAC9IVRw`. Новый
профиль браузера, InPrivate, выключенный кэш и обход service worker исключают
заимствование старых cookies, соединений и загрузок. Системный HTTP-прокси
отключается только для этого окна аргументом браузера; настройки Windows не
меняются. VPN/TUN всё ещё может влиять на сеть, поэтому испытание с ним не
доказывает эффективность DPI-обхода.

Подтверждение требует одновременно:

- ответа медиасервера `*.googlevideo.com/videoplayback` с бинарным типом,
  статусом 200/206 и не менее 32 КиБ свежих сетевых данных;
- именно выбранного видео, без рекламы, с реальными кадрами и непрерывным
  продвижением времени не менее 10 секунд;
- продолжения минимум 2 секунды после перемотки с новыми кадрами;
- не более 4 секунд наблюдавшихся остановок воспроизведения;
- неизменившегося сетевого контекста и подтверждённого возврата конфигурации.

Наблюдения берутся из WebView2 DevTools Protocol и HTMLVideoElement. Окно
работает без пользовательского аккаунта, приглушает звук и закрывается при
завершении. Закрытие пользователем и общая кнопка отмены отменяют испытание.
Ограничение времени — 60 секунд. При достижении наблюдаемого сетевого бюджета
16 МиБ окно уничтожается; размер последнего буфера может дать превышение.
Сохранённые показатели содержат объём, время старта, кадры, остановки,
разрешение и результат перемотки. Подписанные ссылки потоков и cookies не
записываются в историю. Профиль тестового окна удаляется после закрытия;
при удержании файлов браузером удаление повторяется трижды.

Принимаются обычные video/audio MIME и бинарные потоки, включая
`application/vnd.yt-ump` для SABR. Наличие такого ответа само по себе не
подтверждает воспроизведение: обязательны кадры и продвижение времени.
Формат описан в [реализации SABR-плеера](https://github.com/LuanRT/kira#technical-stuff).

403/410/429, серверные ошибки, недоступное видео, инструментирование,
исчерпание бюджета и таймаут дают «не удалось проверить», а не диагноз
«DPI блокирует». Наблюдаемая остановка уже начавшегося воспроизведения даёт
отказ сценария. Этот отказ запрещает применение рекомендации до повторной
проверки. Автоматический и ручной тест видео заменяют предыдущий результат
для той же рекомендации; голосовые проверки Discord сохраняются отдельно.

Источник результата — `player_observation`, область — `whole_configuration`,
транспорт — `unverified`. Испытание не добавляет успешные раунды в турнир,
не подтверждает конкретный блок winws2 и не применяет профиль автоматически.
Наблюдаемый протокол медиазапроса не равен доказательству маршрутизации через
выбранный TLS/QUIC-профиль. Это проверка короткого ролика в наблюдаемом
разрешении, не гарантия 1080p/4K или устойчивости всех CDN.

Следующий этап сборщика: отдельная управляемая проба видеоданных с точной
маршрутизацией к профилю-донору. Текущий плеер уже подключён к найденному
варианту, но пока не включён в массовый перебор каждого кандидата и не
используется как свидетельство для сборки двух профилей YouTube.

Проверки разработки:

```powershell
cargo test --offline --manifest-path src-tauri/Cargo.toml --lib protected_runtime::youtube_playback
cargo test --offline --manifest-path src-tauri/Cargo.toml --lib protected_runtime::zapret2_scenario
node --test scripts/test-youtube-playback-observer.mjs
npm test -- src/design/components/Zapret2ScenarioTrial.test.tsx src/store/zapret2StrategyStore.test.ts src/design/components/Zapret2StrategyPanel.test.tsx src/lib/tauri.browser.test.ts
npm run build
```

Модульные тесты проверяют классификацию наблюдений и защиту применения.
Они не подтверждают доступность YouTube в WebView2 или эффект обхода на
конкретном провайдере. Для этого нужен отдельный запуск в приложении без
VPN/TUN с сохранением результата сценария в истории испытаний.
