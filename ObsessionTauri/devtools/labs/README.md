# Лаборатории интерфейса

Лабораторные страницы перенесены сюда из корня приложения. Запуск из `ObsessionTauri`:

```powershell
npm run dev:labs
```

Каталог: <http://127.0.0.1:1420/devtools/labs/>. Для отдельной страницы добавьте её имя к этому адресу.

Это стенды для разработки тем, анимации и проверки производительности. Они не входят в production-сборку. `overview-dev.html` показывает демонстрационное состояние приложения; сетевые функции в браузере не выполняются.

Точки входа пока находятся в `src/*Lab.*` и `src/*Dev.*`. Общие модули в `src/labs`, компоненты `*SpriteLab` и часть `public/lab-assets` используются рабочими темами. Удалять их вместе со стендами нельзя.

Оставшиеся прототипы сохранены для сравнения. Макеты QuietPond/Axolotl и Autumn Velvet, неиспользуемая сцена крыши и страница `source-art-lab.html` с отсутствующим исходником удалены.

Изображения для стендов Pond Art и Ophanim Observer лежат в `devtools/labs/assets`. Они обслуживаются Vite при разработке и не копируются из `public` в релиз.
