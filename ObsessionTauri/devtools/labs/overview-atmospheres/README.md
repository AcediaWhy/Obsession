# Лаборатория плашек «Обзора»

Запуск из `ObsessionTauri`: `npm run dev`, затем открыть
`http://127.0.0.1:1420/devtools/labs/overview-atmospheres.html`.

Восемь вариантов материалов и эффектов, компактные карточки высотой около 112 px,
переключение демонстрационной защиты, обновления ИИ и потери сети.
Фон и анимации можно отключить отдельно.
Переключатель «Живая поверхность» включает отклик материала на движение курсора
в Golden Meadow, Aurora и Rain; остальные темы сохраняют прежний декор наведения.
Состояния существуют только в памяти вкладки. Кнопка защиты не запускает службы.
Меню показано для оценки композиции; карточки информационные, без переходов.

## Что проверить

- Наведите курсор на карточку: появится тематическая реакция. Быстрый переход
  между карточками плавно возвращает декор. Всплывающих пояснений больше нет.
- Переключите «Живую поверхность», чтобы сравнить реакцию фактуры на курсор.
- Переключите защиту: мягкая волна от точки статуса и тематический эффект проиграются у общей
  плашки, DPI и Telegram. Флажки ИИ и сети меняют только соответствующие карточки.
- Нажмите «Повторить эффекты» несколько раз: декоративный слой заменяется,
  эффекты не накапливаются, карточки сохраняют положение и фокус.
- В Golden Meadow с внешнего края падают два листа. У других тем — сияние,
  алхимическая печать, капли, ночное отражение, солнечный блик, звезда и следы лап.
- «Без анимаций» и системный reduced motion отменяют текущие эффекты.

Декор плавно затухает и удаляется через 4,6 секунды. При смене темы или отключении анимаций
таймер очищается. Наведение меняет цвет поверхности, границу и декор темы.

Стенд использует существующие сцены и миниатюры тем, но собственную разметку
и стили. Основной экран, общие компоненты и конфигурация сборки не изменяются.
HTML отсутствует среди входов релизной сборки; запуск допускается только в DEV
и вне Tauri. Старый `overview-dev.html` сохранён для сравнения.

Проверка типов: `npx tsc -p devtools/labs/overview-atmospheres/tsconfig.json`.
